# Mind-il AI — English video preview

This free proof of concept renders an English AI explainer using Pillow, FFmpeg and Piper's local neural voice. The video uses animated motion graphics, scene-by-scene captions and a separate spoken line for each scene. The generated output requires human review.

In GitHub Actions choose **Mind-il AI English Short → Run workflow**. Download the preview from the run's Artifacts section. A scheduled preview runs daily at 4:00 PM India time.

The voice model is downloaded from Hugging Face during each run. This prototype has one fixed topic; it does not research trends, generate new scripts, or upload videos to YouTube. Voice expression is limited and should be reviewed. No paid API or publishing credentials are used.
